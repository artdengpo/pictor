# Демо-проект: помощь со связью

## Происхождение и границы данных

Это демонстрационный кейс по присланному PDF-брифу. Он полностью синтетический и не описывает реальный продукт МегаФона.

- [`Пример брифа.pdf`](Пример брифа.pdf) — исходный учебный бриф.
- [`brief.md`](brief.md) — адаптированный бриф с решениями, получателями и контрольными точками.
- [`../../data/raw/demo/brief_metrics.csv`](../../data/raw/demo/brief_metrics.csv) — учебные показатели.
- [`../../data/raw/demo/connection_cases.md`](../../data/raw/demo/connection_cases.md) — синтетические сценарии семейной помощи и собственных номеров.
- [`../../data/new/q3_churn_update.md`](../../data/new/q3_churn_update.md) — учебный триггер пересмотра решения.

Материалы не доказывают реальный спрос, частоту проблем, экономику, доступность тарифа или эффективность интерфейса. Демо проверяет сквозной workflow, трассировку фактов, сравнение вариантов, независимую критику и возобновление решения.
