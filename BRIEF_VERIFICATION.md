# Проверка соответствия присланному брифу

## Обязательные пункты

| Требование брифа | Реализация в репозитории | Статус |
|---|---|---|
| ЛПР, получатели, цель и ограничения | `projects/demo/brief.md` | Есть |
| Семейные группы и собственные номера | `data/raw/demo/connection_cases.md`, `artifacts/strategy.md` | Есть |
| Последовательность и альтернатива | Для семьи описаны организация, приглашение, разрешение, передача и статус; для номеров — счёт и устройство | Есть |
| Проверяемая проблема | Главный итог — доля ограничений в 7-дневном окне; порог 12% → 9% | Есть |
| Не меньше 3 содержательно разных вариантов | Оставить как есть, закрыть направление, предупреждение, полноценный кабинет | Есть |
| Сильные возражения у вариантов | `artifacts/options.md` | Есть |
| Продуктовая стратегия | Аудитория, задача, условие помощи, осознанные отказы и проверка | Есть |
| Коммуникационная стратегия | Аудитория, барьер, ключевое сообщение, подтверждение и каналы | Есть |
| План проверки | Единица, сравнение, 7-дневное наблюдение, защитные метрики | Есть |
| Экономическая граница | Разрыв 6 млн руб. и 12 000 дополнительных оплаченных месяцев при учебной ставке 500 руб. | Есть |
| План I–IV кварталов | `artifacts/strategy.md`, `DEMO_CASE_PACK.md` | Есть |
| Ориентир третьего года | Доля подходящих подключённых семейных групп с сохранённой связью | Есть |
| Ресурсы и риски | Дизайн и разработка, проверка, стоп-правила | Есть |
| Возобновление после перерыва | `state/workflow_state.json`, реестр решений и recheck-скрипт | Есть |
| Только открытые/синтетические данные | Явные границы в брифе и данных | Есть |

## Проверка фактов и ограничений

- Факты связаны с графом доказательств.
- Синтетические сценарии явно не выдаются за реальные интервью или пользовательские данные.
- Порог 12% → 9% помечен как иллюстративный и требует согласования в реальной работе.
- Экономика не заменяет расчет с реальными издержками, удержанием и ставками.
- Реальные клиенты, тесты и внешние обязательства требуют отдельного решения человека.

## Решение перед записью видео

Записывать сквозной путь можно по текущему демо-пакету. В результате видео должны быть показаны исходный бриф, факт/гипотеза разделение, варианты, стратегия, план проверки, экономика, кварталы, продолжение и границы полномочий.
