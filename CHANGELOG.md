# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Five built-in art styles and a preview of the prompt sent to the model.
- Local translation of common Russian prompt words into English.

### Removed

- Photo restyling; Pictor now focuses on text-to-image generation.

## [0.1.0] - 2026-11-23

### Added

- Bilingual Russian and English text-to-image prompts.
- Photo restyling with recognizable subject preservation.
- Automatic image validation, preparation, and non-overwriting output names.
- Russian terminal menu and friendly error handling.
- Generated-image history with dates and file sizes.
- Free, local Stable Diffusion generation by default, with an optional paid API provider.
- Bilingual documentation and an actual generated-image example.
