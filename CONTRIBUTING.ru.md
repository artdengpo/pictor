# Участие в проекте

[English](CONTRIBUTING.md) | Русский

## Перед началом

- Для крупного изменения сначала откройте issue или найдите существующий.
- Делайте pull request сфокусированным: один баг или одна функция.
- Никогда не добавляйте в Git `.env`, API-ключи, личные фотографии или приватные результаты.

## Подготовка среды

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
# source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
pytest
```

## Стиль и тесты

- Имена функций и переменных пишите на английском, а пользовательские сообщения и поясняющие комментарии — на русском.
- Публичные docstring’и пишите на английском.
- Разделяйте логику на небольшие функции и покрывайте тестами имена файлов, изображения, язык и обработку ошибок.
- Перед pull request выполните `pytest -q`.

## Issue и pull request

Используйте шаблон бага или предложения и указывайте точные шаги или сценарий.
В pull request опишите изменение, выполненные проверки и приложите скриншот для заметной в интерфейсе или документации правки.
